# 🚆 Step Railway

**Step Railway** is a railway ticket booking website that allows users to search for train journeys, select seats, enter passenger information, and register tickets online.

## 📌 About the Project

Step Railway is a web-based railway ticket booking application developed as a frontend project. It provides a simple and user-friendly interface for searching train schedules and registering railway tickets.

The application communicates with a railway API to retrieve train information and register ticket requests.

## ✨ Features

- Search for train journeys
- View available trains
- Select seats
- Enter passenger information
- User registration and sign-in
- Email verification
- Ticket registration through API
- Ticket confirmation page
- QR code generation
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- Local Storage

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/step-railway.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

   You can also use the **Live Server** extension in Visual Studio Code.

## 🔗 API

The application uses the Step Railway API for train information and ticket registration.

API Base URL:

`https://railway.stepprojects.ge`
